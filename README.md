## Как устроены задания 6–10

Все пять ноутбуков собраны по одному шаблону, чтобы их было удобно проверять:

1. **Подготовка** — импорты, настройки, откуда берутся данные.
2. **Функции** — список функций с описанием, что делает каждая.
3. **Задание 1, задание 2 (и далее)** — код и результат с выводами по каждому пункту.
4. **Выводы** — ответы на вопросы задания с конкретными числами.
5. **Самопроверка** — чек-лист по пунктам задания.

Общие требования выполнены во всех пяти работах:

* код декомпозирован: каждая функция отвечает за одну задачу, дублирующегося кода нет;
* глобальных переменных нет — данные передаются через параметры функций;
* все ячейки выполнены, в ноутбуках сохранены выводы и графики;
* исходные данные лежат рядом с ноутбуком, поэтому работа воспроизводится
  после «Выполнить все».
